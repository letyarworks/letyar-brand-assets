# Letyar Brand Guidelines

## 1. Brand foundation

**Letyar** comes from the Myanmar word **လက်ရာ**, expressing craftsmanship and the maker's fingerprint.

**Core idea:** လုပ်ထားတဲ့ အလုပ်တိုင်းမှာ လုပ်သူရဲ့ လက်ဗွေပါတယ်

**Primary English line:** Every build carries a fingerprint.

**Positioning:** Web · Software · Product

## 2. Visual principle

The identity should feel:

- precise
- crafted
- technical
- minimal
- confident

Avoid visual treatments that make the brand look generic, decorative, or overly effects-driven.

## 3. Mark

The three-groove Letyar geometry is the approved master form.

Always use the supplied artwork. Never reconstruct the mark manually.

### Minimum production preference

- Use SVG whenever the platform supports it.
- Use the supplied PNG exports for raster-only systems.
- Use the favicon/icon exports at small interface sizes.

## 4. Colour system

| Token | Hex |
| --- | --- |
| Ink | #000000 |
| Groove | #1A1714 |
| Lacquer | #E34B2E |
| Thanaka Gold | #D9A441 |
| Cream | #F5F0E6 |

**Lacquer** is the default accent.

**Thanaka Gold** is reserved for premium/global contexts and should not replace the standard accent in everyday product UI.

## 5. Background variants

Choose the supplied variant that provides strong contrast and preserves the intended mark geometry.

Do not place the mark on busy photographic or patterned backgrounds unless the composition has been specifically approved.

## 6. Misuse

Do not:

- stretch or compress the mark;
- rotate or skew it;
- change groove spacing;
- add shadows, glow, bevels, or gradients;
- substitute arbitrary colours;
- redraw or trace the artwork;
- crop the mark in a way that changes its identity.

## 7. Product and web usage

For web products, keep the mark consistent across:

- navigation/header
- favicon
- app icon
- loading/splash screens
- documentation
- social preview assets

Use the smallest supplied icon that preserves clarity rather than scaling a large master unnecessarily.

## 8. Version control

This repository is the canonical source of approved Letyar visual assets.

Production projects should consume assets from a tagged or explicitly approved repository state. When a new master is approved, update this repository before updating downstream products.
